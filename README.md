# ทะเบียนประวัติพนักงาน (Staff Registry)

ระบบบันทึกและจัดการข้อมูลพนักงาน สร้างด้วย **Google Apps Script + Google Sheets**

## คุณสมบัติ
- พนักงานทั่วไป (ไม่ต้องล็อกอิน): เห็นเฉพาะรายชื่อคนที่ยังทำงานอยู่ และกรอกแบบฟอร์มส่งข้อมูลตัวเองเข้าคิวรออนุมัติได้
- แอดมิน (ล็อกอินด้วยรหัสพนักงาน/รหัสผ่านที่เก็บในชีต `Users`): ดูข้อมูลเต็ม เพิ่ม/แก้ไข/ลบพนักงาน และอนุมัติ/ปฏิเสธคำขอที่ส่งเข้ามา
- เมื่อเปลี่ยนสถานะเป็น "ลาออกแล้ว" ระบบใส่วันที่ลาออกให้อัตโนมัติ (แก้ไขได้) และอายุงานจะหยุดนับทันทีที่ลาออก ไม่นับเพิ่มไปเรื่อยๆ

## โครงสร้างไฟล์
| ไฟล์ | หน้าที่ |
|---|---|
| `Code.gs` | โค้ดฝั่งเซิร์ฟเวอร์ (อ่าน/เขียนชีต, ตรวจสอบสิทธิ์แอดมิน) |
| `Index.html` | หน้าเว็บหลัก |
| `Stylesheet.html` | สไตล์ CSS |
| `JavaScript.html` | โค้ดฝั่งไคลเอนต์ |
| `Staff_Info_for_GoogleSheets.xlsx` | ไฟล์ตัวอย่างสำหรับนำเข้า Google Sheets (ชีต `Staff` + `Users`) |

## วิธีติดตั้งและใช้งาน
1. สร้าง Google Sheet ใหม่ แล้วนำเข้า (import) ไฟล์ `Staff_Info_for_GoogleSheets.xlsx` หรือเปิดไฟล์นั้นด้วย Google Sheets โดยตรง — จะได้ชีต `Staff` และ `Users` พร้อมข้อมูลตั้งต้น
2. ในสเปรดชีตนั้น ไปที่ **Extensions → Apps Script**
3. ลบเนื้อหาไฟล์ `Code.gs` เดิม แล้ววางเนื้อหาจากไฟล์ `Code.gs` ในรีโปนี้แทน
4. สร้างไฟล์ HTML ใหม่ 3 ไฟล์ (File → New → HTML) ชื่อ **ต้องตรงเป๊ะ**: `Index`, `Stylesheet`, `JavaScript` แล้ววางเนื้อหาแต่ละไฟล์ตามลำดับ
5. **Deploy → New deployment → Web app** → Execute as: Me → Who has access: ตามต้องการ → Deploy → คัดลอกลิงก์ที่ได้
6. เข้าสู่ระบบแอดมินด้วย `admin` / `1111` (แนะนำให้เปลี่ยนรหัสผ่านในชีต `Users` ทันทีหลังติดตั้ง)

> หมายเหตุ: ระบบนี้ต้องรันอยู่บน Google Apps Script เท่านั้น (ใช้ `SpreadsheetApp`, `HtmlService` ฯลฯ ของ Google) โค้ดบน GitHub repo นี้จึงเป็น **สำเนาเก็บเวอร์ชัน/ย้อนดูโค้ด** — ไม่ใช่เว็บที่รันได้ทันทีผ่าน GitHub Pages แบบเว็บแอปทั่วไป ต้องคัดลอกเข้า Apps Script ตามขั้นตอนด้านบนก่อนถึงจะใช้งานได้จริง
